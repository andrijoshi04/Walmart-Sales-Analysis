# Retail Sales and Product Performance Analysis

## Problem Statement
Retail organizations require insights into product performance, regional sales, and return patterns to improve profitability and optimize inventory management.

## Analysis Performed
A Power BI dashboard was developed to analyze sales and product-level performance across regions. The analysis included:
* Sales performance across different countries
* Brand and product-level sales analysis
* Units sold versus units returned
* Sales trends over time

## Key Insights
* Certain brands consistently outperform others in total sales
* A significant number of units sold are returned, impacting profitability
* Sales performance varies across different regions
* Sales trends fluctuate across time periods

## Business Recommendations
* Focus marketing efforts on high-performing brands
* Investigate causes of high return rates to reduce losses
* Optimize inventory for high-demand products
* Expand operations in regions contributing the highest revenue

## Tools Used
Power BI
